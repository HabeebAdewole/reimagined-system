# Vectogen

Automated generation of API-chained SVGs.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Stability AI](https://stability.ai) — image generation
- [Vectorizer.AI](https://vectorizer.ai) — raster-to-SVG vectorization
- [Supabase](https://supabase.com) — storage & database

## Getting Started

1. Copy `.env.local` and fill in your API keys.
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.
